# TDV Games

🎮 **TDV Community Labs - Məktəb Oyun və Sosial Deduksiya Portalı**

TDV Games məktəb şagirdlərinin birgə intellektual vaxt keçirməsi, sosial deduksiya masalarında strategiya qurması və yeni oyun layihələri üçün nəzərdə tutulmuş rəsmi əyləncə qanadıdır.

## Əsas Layihələr
- **TDV Mafia**: 14 formatlı elit onlayn mafiya platforması ([tdv-mafia.vercel.app](https://tdv-mafia.vercel.app/))
- **Dante's Inferno**: 9 dairəli psixoloji deduksiya rejimi
- **All-In 40-50 nəfərlik masa**: Kütləvi məktəb turnirləri
- **Dostluq Masaları**: Sinif və komandalar üçün xüsusi otaqlar

## Ekosistem
Bu layihə [TDV Community Labs](https://github.com/tdv-community-labs) ekosisteminin rəsmi qanadıdır.
